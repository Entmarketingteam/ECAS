# State Board of Pharmacy — License Database Links

All 50 states publish pharmacy licensee databases. Most are downloadable as CSV or Excel. Use to supplement Apollo for compounding pharmacy owner contacts — state boards are more complete for small independents.

Filter for: Active license status + compounding designation where available.

## How to Use

1. Go to state board URL
2. Search for "compounding" license type or pharmacy specialty designation
3. Export CSV (most states support this)
4. Fields to extract: License holder name, business name, address, city, zip, phone, email (where available), license status, license type
5. Cross-reference with Apollo for decision-maker name/email enrichment
6. Dedupe before loading to Findymail/Smartlead
